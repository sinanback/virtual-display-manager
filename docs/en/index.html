THE PROBLEM → A DISPLAY SOURCE

Connected, but no picture?

On some Windows systems, unplugging a monitor leaves no active screen for remote-access software to capture. You may see a black screen or “waiting for image”. VDD adds a software monitor; this utility manages when it is enabled.

  1. 01

    No monitor: enable VDD.

    While the manager runs, an installed, disabled VDD is enabled when no physical display is active.

  2. 02

    Monitor connected: disable VDD.

    The virtual display is disabled when at least one active physical monitor is detected.

  3. 03

    Last monitor unplugged: restore VDD.

    Two consistent samples confirm a change. Uncertain detection preserves the current state.

This utility does not establish remote connections or fix network, password or session issues. It addresses the display-source problem; not every black screen is caused by a missing monitor.

FAQ

Before you download

Can this replace a physical HDMI dummy plug?

In suitable Windows, driver and remote-capture configurations, a software virtual monitor can serve the same display-source need. Compatibility with every setup is not guaranteed.

Does it work with AnyDesk, TeamViewer or other remote tools?

It depends on capture support and software version. Application-specific compatibility has not been tested for this project. Some tools already provide their own virtual-monitor support.

Does a built-in laptop screen count?

Yes. An internal panel reported as an active physical display counts. Automatic mode disables VDD while it is active.

Does closing the window stop monitoring?

No. The close button hides the window to the notification area. Use the tray menu’s Exit application action to stop monitoring.

What has been tested?

This is a public preview. UI, simulated switching, icon, startup and read-only hardware checks passed. Actual cable changes and driver installation/removal were not tested in this release preparation. Verify it on a test device first.

Can it interrupt remote access?

Manually disabling VDD without a physical display may remove the remote picture. Keep an alternative access method when testing device changes.
